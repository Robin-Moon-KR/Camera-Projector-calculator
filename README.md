Camera and Lens Information Input

 - Select from a pull-down menu or directly enter the sensor size.

 - Input the lens information.

Display Calculation Results for Maximum Wide and Maximum Zoom

 - Upon entering the above information, the calculation results for both the maximum wide angle and maximum zoom are displayed at the bottom.

Manual Focal Length Adjustment for Screen Size Calculation

 - In the center of the results, manually change the focal length to calculate the screen size.

Target Screen Width Input for Focal Length Calculation

 - Specify the horizontal width of the screen to calculate the corresponding focal length.

Aspect Ratio Calculation

 - Calculations are performed based on the standard 16:9 aspect ratio.
